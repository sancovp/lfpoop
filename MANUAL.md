# LFPOOP Manual

## Least-Fixed-Point Object-Oriented Programming

## Purpose

LFPOOP is **not** primarily a framework for building applications.

It is a recursively self-expanding **metacompiler** whose observable
outputs happen to be applications, skills, agents, packages, manuals,
and runtimes.

The compiler is the product. Everything else is evidence.

# Goldenization

Every artifact begins **hot**.

It is progressively cooled through:

-   execution
-   testing
-   relational validation
-   observation
-   independent witnessing
-   provenance
-   append-only crystallization

Only cooled structures become canonical compiler knowledge.

------------------------------------------------------------------------

# Compiler Loop

``` text
while true

    observe()

    classify()

    infer_next_closures()

    for closure

        materialize()

        execute()

        test()

        graph()

        quarantine()

        if witnessed_effect()

            goldenize()

            improve_compiler()

repeat
```

# Mixin Rule

Whenever a reusable class appears, lift it into a categorical mixin
suitable for dependency injection.

Mixins become reusable production operators capable of generating APIs,
libraries, applications, and services.

------------------------------------------------------------------------

# Agentification

Every executable object may automatically receive:

-   explanation
-   evolution
-   testing
-   export
-   review
-   graph identity

At that point it becomes an agent.

------------------------------------------------------------------------

# Reflection

Programs become graph objects.

Graph objects become agents.

Agents improve the compiler that generated them.

The compiler therefore continually recompiles itself through its own
descendants.

------------------------------------------------------------------------

# Ultimate Goal

Produce a self-expanding metarepository proving LFPOOP through
recursively generated artifacts.

Applications are executable proofs.

The compiler is the actual product.
